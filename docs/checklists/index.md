# 清单工具

> 用清单对抗情绪和遗漏——投资里最廉价的风控。

## 投资前检查清单

- [ ] 这门生意我真的看得懂吗？（在能力圈内）
- [ ] 它靠什么赚钱，护城河是什么？
- [ ] 关键假设有哪些？最可能错在哪？
- [ ] 现在的价格相对内在价值，安全边际够吗？
- [ ] 如果跌 30%，我的逻辑会变吗？敢加仓吗？
- [ ] 仓位是否在我能承受的范围内？

## 调研模板

- 生意：卖什么、卖给谁、怎么收钱
- 财务：成长性、盈利质量、现金流、负债
- 管理层：是否诚信、是否善待股东
- 风险：政策、竞争、技术替代、单一依赖
