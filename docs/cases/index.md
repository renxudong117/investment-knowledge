# 案例复盘

> 实践记录区：个股/行业研究笔记 + 买卖记录 + 事后复盘。

## 怎么记一个案例

建议每个案例单独建一个 `.md` 文件（如 `docs/cases/example.md`），并在
`docs/.vitepress/config.mts` 的 sidebar 里登记。推荐结构：

1. **一句话逻辑**：为什么看好/看空
2. **关键假设**：哪几条成立这笔投资就成立
3. **估值**：当时怎么算的，留了多少安全边际
4. **决策**：买/卖的时间、价格、仓位
5. **复盘**：事后回看，哪对了、哪错了、下次改什么
