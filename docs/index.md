## 关于这个知识库

这里用来系统地记录我的**投资逻辑**：不是记"买了什么"，而是记"为什么这样想"。
目标是让每一次决策都可追溯、可复盘、可迭代。

四个栏目对应一套闭环：**框架**定方向 → **估值**做判断 → **案例**记实践 → **清单**保纪律。
