## 关于这个知识库

这里用来系统地记录我的**投资逻辑**：不是记"买了什么"，而是记"为什么这样想"。
目标是让每一次决策都可追溯、可复盘、可迭代。

四个栏目对应一套闭环：**框架**定方向 → **估值**做判断 → **案例**记实践 → **清单**保纪律。

## 投资信条

> 用一句话能说清的核心原则放在这里，时常回看，对抗一时的情绪。

- **只投看得懂的**：能力圈之外的机会，再诱人也放弃。
- **价格之外先看生意**：先判断生意好不好，再判断价格贵不贵。
- **留足安全边际**：承认自己会算错，用折让对冲判断误差。
- **逆向但不盲目**：别人恐惧时关注，但只在逻辑成立时出手。
- **少动多想**：决策越少越慎重，长期复利来自不犯大错。
