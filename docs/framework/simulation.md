# 投资推演：200万半仓起点的30日策略模拟

> **推演参数**  
> 总资金 **200万元**，半仓起点：100万已建仓（成本 **15元/股**，约66,667股），现金 **100万元**。  
> 模拟周期：**30个交易日**。所有策略均可加仓也可减仓，管理全部200万。

---

## 一、五种价格情景

市场未来走势无法预测，但可以归纳为五种主流路径，并赋予概率权重：

| 情景 | 概率 | 特征 |
|------|------|------|
| ↑ 持续上涨 | 15% | 单边趋势，每日小幅上行 |
| ↑↓ 先涨后跌 | 25% | 冲高后回落，M形走势 |
| ↔ 震荡横盘 | 20% | 围绕建仓价上下波动 |
| ↓↑ 先跌后涨 | 25% | 先回调后修复，W形走势 |
| ↓ 持续下跌 | 15% | 单边下行，每日小幅阴跌 |

## 二、五种投资策略

所有策略的**起点相同**（半仓），均可在30日内自由加仓或减仓：

| 策略 | 核心逻辑 |
|------|----------|
| **持仓不动（基准）** | 不追加投入，也不减仓，纯粹持有观察 |
| **DCA 等额定投** | 每日将剩余现金平均买入，不主动减仓 |
| **追涨杀跌** | 涨幅>1.5% 追加买入；跌幅>1.5% 减仓止损 |
| **逢跌加仓/高位减仓** | 跌幅>2% 加仓；涨幅>2% 减仓 |
| **止损止盈** | 总亏损>10% 清仓；总盈利>20% 减半 |

## 三、各情景下的总资产演变

下图展示每种情景中，五种策略的30日总资产走势（含已持仓+现金）：

![各情景下各策略总资产演变](/sim/fig2_equity.png)

**关键观察：**
- **持续上涨**时，追涨杀跌（不断追买）资产增值最快
- **持续下跌**时，追涨杀跌（不断止损）反而损失最小（逢跌加仓亏损最惨）
- **震荡横盘**时，DCA定投表现最稳健
- **先跌后涨**时，持仓不动优于追涨杀跌

## 五、追涨杀跌：什么时候对，什么时候错？

![追涨杀跌验证](/sim/fig4_verdict.png)

### 各情景下追涨杀跌 vs 逢跌加仓的胜负

| 情景 | 追涨杀跌 | 逢跌加仓 | 谁更优 |
|------|---------|---------|--------|
| ↑ 持续上涨 | **+36.4%** | +17.5% | ✅ 追涨杀跌 |
| ↑↓ 先涨后跌 | -3.0% | -5.9% | ✅ 追涨杀跌（亏得少） |
| ↔ 震荡横盘 | +2.7% | +3.8% | ✅ 逢跌加仓 |
| ↓↑ 先跌后涨 | +11.3% | -5.0% | ✅ 追涨杀跌 |
| ↓ 持续下跌 | -11.9% | **-50.3%** | ✅ 追涨杀跌（大幅领先） |

### 结论

**追涨杀跌在4/5的情景中表现不差，在单边趋势行情中表现最好。**  
逢跌加仓的致命弱点：**持续下跌时不断摊低成本，亏损无底洞（-50.3%）**。

> 追涨杀跌本质是"顺势而为"——它的前提是**趋势确实存在**。  
> 如果行情只是短期波动（震荡横盘），追涨杀跌会反复被"假突破"打脸，交易成本侵蚀收益。

## 六、概率加权下的推荐操作方案

![每周操作节奏与决策树](/sim/fig5_plan.png)

### 30日资金部署节奏

| 周次 | 计划加仓 | 条件减仓 | 核心策略 |
|------|---------|---------|---------|
| 第1周（D1-5） | 10万 | 0 | 轻仓观察，摸清方向 |
| 第2周（D6-10） | 15万 | 0 | 方向初现，开始建仓 |
| 第3周（D11-15） | 20万 | 5万 | 加速布局，高位适当减 |
| 第4周（D16-20） | 20万 | 5万 | 主力买入窗口 |
| 第5周（D21-25） | 20万 | 5万 | 视情景调整 |
| 第6周（D26-30） | 15万 | 5万 | 收尾，锁定收益 |

### 每日操作三原则

1. **涨幅 > 2%** → 按计划买入，但减半，避免追高；已盈利部分可减10-15%
2. **±2% 以内** → 严格执行DCA等额定投，不因波动改变节奏
3. **跌幅 > 2%** → 按计划买入量×1.5倍加仓，逢跌摊薄成本

### 保护性触发线

| 触发条件 | 动作 |
|---------|------|
| 总亏损 > **10%**（总资产跌破180万） | 减仓至两成持仓，停止加仓，等企稳信号 |
| 总盈利 > **20%**（总资产超过240万） | 减仓至五成，锁定一半利润 |
| 单日跌幅 > **5%** | 暂停当日计划买入，次日观察再决定 |

## 七、一张图总结

```
情景概率权重下，最优资金部署逻辑：

  持续上涨（15%）→ 追涨买入效果最好，但概率偏低
  先涨后跌（25%）→ 前半程追涨，后半程必须止盈减仓
  震荡横盘（20%）→ DCA定投稳稳赚，追涨杀跌反复被割
  先跌后涨（25%）→ 忍住不杀跌，跌深时加仓，反弹后减
  持续下跌（15%）→ 严格止损，不摊低成本，保住本金

  综合最优解：
  ① 第1-2周轻仓观察，判断方向
  ② 有方向→顺势加仓（追涨可以，但控制节奏）
  ③ 无方向→DCA等额定投，不做判断
  ④ 亏损扩大→坚决减仓，不要"等回来"
  ⑤ 盈利丰厚→分批止盈，不要全押到底
```

> **核心认知**：追涨杀跌不是坏策略，但它需要**你判断对趋势**。判断对了，它是最优策略；判断错了（震荡行情），它是最差策略。DCA等额定投虽然期望收益不高，但它**不需要你判断对**，是"懒人最优解"。
